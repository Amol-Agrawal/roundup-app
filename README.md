# RoundUp

Android app for a doctor's team: record hospital visits on the phone, share them with the team, and track which visits
the hospitals have paid.

**Download the latest version from [Releases](https://github.com/Amol-Agrawal/roundup-app/releases/latest).**

This repository holds only the app downloads; the source code is private.

## Installing
1. On the Android phone, open the latest release and download the `.apk` file.
2. Open it. If Android asks, allow your browser or Files app to install unknown apps, then tap **Install**.
3. Open RoundUp and sign in, or create your account and ask your team's admin to invite you.

Updates install over the old version and keep your data; the app tells you when a new version is available.
